# HRIS by Khwarizmi — Landing Page

Landing page HRIS by Khwarizmi. Stack & gaya UI sama dengan landing Khwarizmi Workspace
(SvelteKit + Tailwind v4 + GSAP, prerender statis, deploy ke Cloudflare Pages), dengan palet
warna hijau HRIS (`brand-*` di `src/routes/layout.css`).

```bash
npm install
npm run dev       # development
npm run build     # output ke build/
npm run deploy    # build + wrangler pages deploy
```

Kontak (WhatsApp, email, Instagram) diatur di `src/lib/config.ts`.
